# The Automation Guys — Operations, Rewired

Marketing site & web application for **The Automation Guys** — an AI automation & operations agency.

## Stack
- **Framework**: Next.js 16 (App Router + Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS + Custom Design Tokens (Light/Dark themes)
- **Animations**: Framer Motion, GSAP, WebGL raymarching canvas
- **Deployment**: Vercel

## Features
- **Hero Section**: Photorealistic static WebGL Black Hole backdrop with clear value copy overlay.
- **Light & Dark Theme**: Custom theme provider supporting instant toggle with persisted preference.
- **Interactive Per-Module Dissolve QR**: HTML5 Canvas 2D per-cell staggered opacity dissolve QR code.
- **Service Cards & Method Timelines**: Responsive grid layouts with staggered motion reveals.
- **Interactive Custom Cursor**: Fluid electric blue trailing halo dot cursor.
- **Global Gridlines Pattern**: Technical background grid overlay adapting across dark and light themes.

## Getting Started

First, install dependencies and launch the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to preview the app.

## Build for Production

```bash
npm run build
```
